# Refinamento visual Flutter

Design System central em lib/design_system.dart: superfícies neutras, títulos
com peso 600, ícones monocromáticos, campos suaves, cantos proporcionais e
bottom sheets com 28 px. Serviços Turmas/Tarefas em grelha adaptativa com
rotas reais. Texto ampliado ou largura pequena colapsa a grelha para uma coluna.
Disciplinas usam icon wells neutros, sem uma cor diferente por disciplina.
Tema escuro mantém contraste e superfícies próprias; gradiente só na identidade.

Não foram acrescentados atalhos fictícios de GPS, pagamentos ou fornecedores.
Inter empacotada e morph do S original permanecem pendentes. Este incremento
foi revisto em código, sem build/render Flutter; validação visual ainda necessária.
