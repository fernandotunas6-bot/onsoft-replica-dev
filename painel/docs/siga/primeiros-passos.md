# Primeiros passos da escola

Depois de criar a escola no portal WEB, o Administrador entra no SIGA e encontra no painel o cartão **Primeiros passos**. O cartão mostra o que falta fazer, pela ordem em que as coisas dependem umas das outras, e cada passo fica marcado quando o SIGA encontra os dados na base.

O mesmo percurso está no assistente **Configurar a escola** (`/configuracoes/inicio`).

## As quatro fases

| Fase       | Passo                                                                             | Onde se faz                       |
| ---------- | --------------------------------------------------------------------------------- | --------------------------------- |
| Base       | Confirmar os dados da escola: nome, NIF, morada, contactos                        | Definições → Escola               |
| Base       | Definir o ano lectivo                                                             | Calendário                        |
| Base       | Gravar os três trimestres, ou os dois semestres numa escola só de Ensino Superior | Calendário                        |
| Pedagógica | Preparar cursos e classes                                                         | Pedagógica → Estrutura académica  |
| Pedagógica | Rever as disciplinas                                                              | Pedagógica → Disciplinas          |
| Pedagógica | Criar as turmas do ano                                                            | Pedagógica → Turmas               |
| Pedagógica | Publicar o modelo de avaliação, ou rever o regulamento no Ensino Superior         | Pedagógica → Modelos de avaliação |
| Financeiro | Definir propina e matrícula                                                       | Definições → Financeiro           |
| Pessoas    | Convidar a equipa                                                                 | Acessos                           |
| Pessoas    | Matricular ou importar os alunos                                                  | Alunos, ou Importar               |
| Pessoas    | Abrir a matrícula online                                                          | Definições → Matrícula pública    |

## Dicas

- **Calendário do MED.** Ao criar o ano lectivo, o SIGA sugere as datas do calendário escolar nacional. Confirme-as antes de gravar.
- **Um só ano activo.** Activar um ano novo fecha o anterior. Nada é apagado.
- **Modelos de estrutura.** Em Estrutura académica pode aplicar um modelo por nível de ensino, do Primário ao II Ciclo e ao Ensino Superior, em vez de criar classes e disciplinas uma a uma.
- **Sem modelo de avaliação não há pauta.** A pauta oficial só se gera depois de publicar um modelo de avaliação.
- **Importar em vez de escrever.** Se a escola já tem listas em Excel, use os modelos oficiais em **Importar**. Veja [Alunos e matrículas](/siga/alunos-e-matriculas).
