        INSTALAÇÃO E PRIMEIRO ACESSO
      

      
Comece com confiança.

      

        Use os instaladores oficiais publicados pela OnSoft. A aplicação não pede a senha da escola
        durante a instalação.
      

      
    
        
  1. 
          Windows
          
    
            Execute o instalador, confirme a origem do ficheiro e siga as instruções. A instalação é
            feita para o utilizador actual. Se necessário, o instalador obtém o Microsoft WebView2
            pela Internet.
          
    
        
    2. 
        
  2. 
          macOS
          
    
            Abra o ficheiro DMG e arraste o SIGA Desktop para Aplicações. Não ignore avisos de
            assinatura ou segurança do sistema.
          
    
        
    3. 
        
  3. 
          Entrar na escola
          
    
            Abra o SIGA, verifique a ligação e autentique-se no portal. O acesso depende do seu
            vínculo e das permissões escolares.
          
    
        
    4. 
      

      

        Antes de começar
        

          Precisa de Internet para o portal e de uma conta escolar autorizada. Catracas e
          impressoras exigem configuração própria; o daemon Python é instalado separadamente.
