# SIGA Plus — revisão de detalhes da interface

Revisão de 01/10/2026, na PR #35. Foram ajustados componentes partilhados e a lista de Alunos, preservando o design e os fluxos existentes. As capturas abaixo são de uma página local com os componentes reais e dados fictícios; a página de revisão não autentica nem consulta o SGA.

## Correcções aplicadas

| Área                    | Resultado                                                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tipografia e toque      | Base mobile de 16 px; campos legíveis; botões e campos partilhados com altura mínima de 44 px abaixo de 768 px. A densidade do desktop foi preservada.                                      |
| Filtros e pesquisa      | Pesquisa ocupa uma linha no telefone; filtros secundários recolhem abaixo de 640 px; valores longos e filtros activos cabem no contentor.                                                   |
| Paginação e tabs        | Controlos maiores no telefone, identificação acessível da página e tabs que mantêm os nomes sem sobreposição.                                                                               |
| Lista de Alunos         | Cartões com selecção, estado académico/financeiro, turma, ano, encarregado e contactos. Acesso ao modal existente e à ficha; opção de tabela completa para todas as acções existentes.      |
| Selecção entre páginas  | O checkbox da página reflecte os IDs presentes nessa página, incluindo selecção parcial, em vez de comparar apenas a quantidade seleccionada.                                               |
| Formulários em modais   | Rodapé acessível com conteúdo rolável; campos `required` e `type=email` bloqueiam envios inválidos; envio válido chama a acção uma vez. O rodapé independente mantém a sua acção explícita. |
| Fecho e teclado         | `preventOutsideClose` respeitado; foco devolvido ao accionador; títulos de diálogo acessíveis; passos anteriores do wizard são botões operáveis por teclado.                                |
| Cabeçalhos e selectores | Textos longos adaptam-se; só o último breadcrumb é o destino actual; indicadores recolhidos ficam fora da navegação por teclado.                                                            |

## Verificação reproduzível

Com Node 24 e as dependências instaladas:

```sh
npx playwright install chromium
npm run check:responsive
```

O comando inicia uma página Vite local em `127.0.0.1:3016`, testa os componentes em Chromium e grava capturas e resultados em `reports/responsive-review`. Usa movimento reduzido. Os dados de exemplo e a página estão em `tests/fixtures/responsive-review`; não são uma rota do produto.

| Dimensões (px) | Claro    | Escuro   |
| -------------- | -------- | -------- |
| 320 × 900      | Aprovado | Aprovado |
| 375 × 900      | Aprovado | Aprovado |
| 390 × 900      | Aprovado | Aprovado |
| 768 × 900      | Aprovado | Aprovado |
| 1024 × 900     | Aprovado | Aprovado |
| 1440 × 900     | Aprovado | Aprovado |
| 320 × 480      | Aprovado | Aprovado |
| 640 × 360      | Aprovado | Aprovado |

As verificações cobrem largura do conteúdo, filtros, pesquisa com debounce, selecção de cartões, paginação, navegação de tabs por teclado, selector com texto longo, limites dos diálogos e acesso ao rodapé. Verificam também bloqueio de envios inválidos, envio válido único, restauração do foco, wizard por teclado e bloqueio de fecho exterior. Não foram detectados erros de execução na página de revisão.

Na rota real de Alunos, os testes de render verificam o contexto de candidatos no telefone, a passagem para a tabela completa e a selecção entre páginas, além dos casos existentes de carregamento, estados vazios e realtime.

## Limites

Esta revisão valida os componentes indicados e os casos de Alunos cobertos pelos testes. Não equivale a percorrer todas as rotas autenticadas, todas as permissões/planos ou todos os formulários com dados reais. Fichas e listas específicas dos restantes módulos continuam a precisar dessa revisão.

Não foram verificados Safari, dispositivos físicos, teclado virtual, instalação PWA, funcionamento offline ou áreas seguras de dispositivos reais. Não houve publicação nesta revisão; os resultados dizem respeito ao código local da PR.
