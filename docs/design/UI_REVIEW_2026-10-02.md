## Reprodução

Com Node 24 e as dependências do projecto instaladas:

```sh
npx playwright install --with-deps chromium webkit
npm run check:responsive
```

O comando falha se um navegador ou cenário falhar; não converte indisponibilidade em aprovação. `SIGA_REVIEW_BROWSERS=chromium` permite executar só Chromium, mas esse resultado cobre apenas 16 cenários. O WebKit desta revisão correu em Linux com dependências nativas fornecidas num runtime temporário e um wrapper definido por `SIGA_REVIEW_WEBKIT_EXECUTABLE`; a versão do motor consta dos resultados. Não foi usado Safari instalado em macOS ou iOS.

## Revisão autenticada preparada, por executar

Existe agora `npm run check:responsive:authenticated`, que exige uma sessão Playwright já autorizada em `SIGA_REVIEW_STORAGE_STATE`, aceita `SIGA_REVIEW_URL` e percorre Alunos, Pedagógica, Calendário, Finanças e RH em Chromium/WebKit, a 390 e 1440 px. As rotas podem ser ajustadas com `SIGA_REVIEW_ROUTES` aos acessos do perfil em revisão.

O script faz uma pré-verificação de navegação, render e largura. Bloqueia pedidos de escrita da aplicação, permite renovação de autenticação e guarda capturas em `reports/authenticated-ui-review`, fora do Git. Não grava credenciais ou tokens no relatório. Não substitui a inspecção humana dos dados, formulários, permissões e operações de cada módulo.

Não foi executado nesta sessão: não existe uma sessão escolar autorizada disponível neste checkout. O preflight sem sessão falha com uma instrução explícita, sem produzir uma falsa aprovação.
